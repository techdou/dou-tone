# dou-tone Agent 匹配回归用例

这些用例用于人工或 Agent eval，重点检查 discovery 阶段是否根据 `SKILL.md` 的 `name + description` 正确决定是否使用 `dou-tone`。

## 应触发

1. `帮我润色一下这份工作总结，事实和数字别改。`
2. `把这些口述需求整理成给甲方看的正式项目方案。`
3. `这段开题报告语言有点口语，按硕士论文风格深度润色。`
4. `把下面的教学设计改得更自然、正式一些，内容不要扩写。`
5. `把这几条要点整理成一页 PPT 的标题和正文。`
6. `用我的语气把这些材料写成公众号文章，不要有 AI 味。`
7. `重写这段 README，让项目能力和限制更清楚。`

期望：使用 `dou-tone`，并根据任务选择正确改写级别和主场景。

## 不应触发

1. `什么是多模态融合？`
2. `帮我找三篇最新的遥感多标签论文。`
3. `解释一下 softmax 和 sigmoid 的区别。`
4. `这个 Python 报错怎么修？`
5. `把这段英文忠实翻译成中文，不要改写。`
6. `提取这份报告里的所有日期和金额。`
7. `总结这篇论文的方法和实验结果，方便我理解。`
8. `把这份 Word 转成 PDF。`

期望：不要仅因为内容涉及科研、项目、教学或文档而使用 `dou-tone`。

## 组合触发

1. `解释这篇论文的方法，然后把我的理解整理成讨论班汇报稿。`
   - 前半段不需要 `dou-tone`；整理汇报稿阶段使用。
2. `修复这个接口 bug，并帮我写一段 PR 描述。`
   - 代码修复不由 `dou-tone` 负责；PR 描述可使用。
3. `把这份报告生成 DOCX，并顺便润色正文。`
   - 文件生成由文档/Artifact 能力负责；文字层使用 `dou-tone`。
4. `把这段英文翻成中文并改成正式报告口吻。`
   - 翻译与文体改写同时存在，可使用 `dou-tone` 处理改写层。
5. `做一份科研汇报 PPT。`
   - 如果任务包含页面文案写作，可使用 `dou-tone` 的学术 + PPT 规则；幻灯片文件生成由 `ppt-studio` 负责。

## 失败判定

出现以下任一情况视为匹配质量问题：

- 仅因主题是科研/教学/项目就自动触发。
- 用户明确要求润色/重写却未触发。
- 触发后一次性加载全部 `references/`。
- 与专业 Skill 或 Artifact Skill 竞争并重复执行其职责。
- 因 Skill 默认规则覆盖用户本轮明确指令。

## 写作行为验收

以下是待执行的人工或独立评估用例，不表示已经通过模型实测。检查含义和范围，不要求逐字复现某个答案。

| 用户请求与材料 | 验收要点 |
|---|---|
| “只校对：我已经把问题搞清楚了，明天再改。” | 可原样交付；保留虚词、口语和未来状态，不改成正式公文 |
| “润色，保留结构：拟于周四开放预览，效果尚未测试。” | 保留计划和未测试状态；不补上线成果或用户反馈 |
| “润色：控制器通过闭环反馈调整输出。” | 保留“闭环”的专业含义，不按黑话删除 |
| “去 AI 味：研究表明该方法适用于低温条件[1]。” | 引文归属与限定条件不消失；文献未提供时不编出处 |
| “保留我的判断：我更喜欢第二种方案，因为它允许离线编辑。” | 保留第一人称评价与既有理由，不改成无作者判断的产品清单 |
| “按我的样本写。样本：我去年上线了三个工具。目标材料：本工具计划下月测试。” | 只借用表达节奏，不挪用样本经历，不改计划状态 |
| “校对：延迟发生在渲染阶段，而不是上传阶段。” | 保留真实对比，不按假对比模式删去否定信息 |
| “整理成稿：把要点写入草稿，检查草稿，再导出报告。” | 保留对象和步骤关系，不为简短删成无法理解的碎句 |
| “润色：从 80% 到 88%，提升 8%。” | 识别百分点与相对增幅口径，给出复算依据或待核对说明，不悄悄照抄或改数 |
| “润色此 README，但不要修改代码、命令和链接目标。” | 正文可改，受保护内容保持不变；改标题时检查锚点引用 |
| “去 AI 味：预计会在一定程度上影响结果，但可能不会改变排序。” | 保留两个不同判断各自的不确定性，不机械合并全部限定 |
| “根据三条要点起草一则通知。” | 写作请求可以触发；材料不足的日期、负责人不虚构补齐 |
| “润色方案说明：四条完整句子的 bullet 共同解释同一个原因。” | 按句间关系考虑段落组织；不因数量达到阈值就强制合并，不补造因果 |
| “校对这份四步操作清单，保留列表。” | 保留真实步骤与指定格式；结构提醒不得越过 L1 范围 |
| “润色三段各一句的海报文案，保留分段和语气。” | 不跨段落拼接成所谓碎句，不强行凑段落句数 |
